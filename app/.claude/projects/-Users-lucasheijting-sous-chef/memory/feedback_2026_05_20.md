## Lijsten
- "Verwijder afgevinkte items" must ONLY appear when user actively checks an item in current session; auto-hides after 7s. Bug: shows on initial load if items are pre-checked.
- Text input for "item toevoegen" gets hidden by keyboard when typing → need KeyboardAvoidingView.
- Same keyboard issue for "lijst toevoegen" modal in index.tsx.

**Why:** Usability — sticky bottom bar gets covered; batch delete button is distracting.
**How to apply:** Use hasInteractedRef to gate batchDelete visibility; wrap list detail and new-list modal in KeyboardAvoidingView.

## Menubalk
- Icons not visible enough (inactive color #555 is too dark on glass dark background).
- Tab bar still spans full screen width despite left/right margins → use fixed width centered approach.

**Why:** Icons wash out on the dark glass pill; pill shape doesn't float if it spans full width.
**How to apply:** Inactive color → rgba(255,255,255,0.55); use Dimensions to compute fixed ~260px bar centered.

## Agenda
- Remove stat tile counters from both banners (today/this week counts).
- Remove period + category filter chips from full (uitgebreid) mode entirely.
- Replace settings-based lite/uitgebreid toggle with a single icon button in the banner that switches modes at runtime.
- Enable deleting phone calendar events (Calendar.deleteEventAsync); sous-chef events also need CalDAV backend delete endpoint (deferred).

**Why:** Cleaner UX, more room for actual events.
**How to apply:** Restructure AgendaTab → AgendaWrapper with local state; AgendaFull loses filters; both show icon toggle in banner.

## Instellingen
- Profile section needs multiple-choice questions for easy profile filling (dietary, household, work, etc.) — full UX redesign needed.
- Feedback modal already exists with Supabase save. Add WhatsApp send option as secondary button.

**Why:** Profile via free text is tedious; users need a guided experience.
**How to apply:** Profile modal → step-by-step multi-choice wizard. Feedback modal → add "Via WhatsApp" button opening whatsapp deep link.
